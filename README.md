# Perihelion

A cinematic, interactive web experience for the **ASTRA Astronomy and Astrophysics Club** newsletter. 

The site features a scroll-driven starry background where each month's newsletter is mathematically plotted along an analemma (the figure-eight path the Sun traces in the sky over a year). 

## Features
- **Scroll-Driven Design:** Smooth, scroll-linked animations mapped against a dynamic warp-speed starfield.
- **Cinematic Reader:** A frosted-glass overlay modal to read editions without leaving the immersive space background.
- **Custom Interactions:** A target-lock cursor that frames interactive elements, alongside vibrant, space-themed social buttons.
- **Lightweight:** Built entirely with standard HTML, CSS, and Vanilla JavaScript—no heavy frameworks required.

## Usage
No build steps are required. Simply rename the `.html` file to `index.html` and open it in any modern web browser to view the site locally.

## Deployment
This static project can be hosted for free by dropping it into **GitHub Pages**, **Vercel**, or **Netlify**.
